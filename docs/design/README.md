Os mockups em `mockups/<module>/` são especificações visuais obrigatórias. Antes
de implementar UI:

1. Ler o PRD do módulo.
2. Abrir o design system.
3. Abrir todos os estados de mockup aplicáveis.
4. Implementar loading, vazio, erro, permissão e responsividade.
5. Validar o resultado em browser antes de declarar conclusão.
