Visão geral do handoff

Este painel renderiza documentos Markdown allowlisted do repositório. Não é editor, não consulta tickets e não expõe caminhos internos, segredos ou dados de clientes.

Somente ADMINFonte: docs/handoffCommit: 29c1639
Busca retorna somente título e trecho de documentos permitidos. Um erro ou documento ausente não revela o caminho físico.

Fluxo de leitura

ADMIN autenticado → índice allowlisted → documento lógico → Markdown seguro
ADMIN autenticado → termo válido → busca server-side → hits navegáveis

Estados obrigatórios

Skeleton durante carregamento, vazio em busca sem resultado, retry para erro de rede e página proibida sem conteúdo para qualquer role diferente de ADMIN, inclusive ROOT.

Acesso restrito

Esta Base Técnica é exclusiva para administradores autorizados.
