# Qualidade

Relatórios de QA ficam em `reports/<module>/`. Cada novo relatório deve informar:

- data e escopo;
- PRD e mockups usados;
- ambiente e commit verificados;
- resultados por Banco, API/Backend e Frontend/UI;
- evidências, riscos e itens não validados.

Relatórios históricos não substituem validação atual do runtime.
