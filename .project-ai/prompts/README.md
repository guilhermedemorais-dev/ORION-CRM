# Prompts Locais

Não há prompt ativo que substitua o workflow definido por `AGENTS.md` e
`docs/DEVELOPMENT_WORKFLOW.md`.

O diretório `archive/` preserva prompts históricos migrados da antiga árvore de
PRDs. Eles podem conter checkpoints, stack ou padrões desatualizados e não devem
ser executados sem revisão contra os documentos canônicos atuais.
