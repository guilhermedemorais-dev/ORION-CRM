# Regras de UI

- Fonte visual: `docs/design/design-system/ORION-DESIGN-SYSTEM.html`.
- Mockups em `docs/design/mockups/<module>/` são especificações obrigatórias.
- Não inventar layout ou interação quando houver referência aprovada.
- Incluir skeleton, empty state, error state e responsividade.
- Verificar o resultado renderizado antes de declarar a tela pronta.
