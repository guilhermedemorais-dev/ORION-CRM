# Regras do Projeto

- Ler `AGENTS.md` e `docs/README.md` antes de trabalhar.
- Ler o PRD do módulo antes de modificar código.
- Usar apenas o runtime `docker compose` da raiz.
- Não alterar stack, contratos ou requisitos sem decisão explícita.
- Não declarar trabalho concluído sem evidência de validação.
- Separar relatórios em Banco, API/Backend e Frontend/UI.
